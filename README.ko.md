# gollabara

> 세션은 흐르고, 너는 골라 봐라

Open Design · Claude Code · Codex · Claude Design 세션이 만들어 내는 **산출물**(스크린샷 · 시안 · 턴 끝 리캡 · 세션이 물은 질문)만 하나의 흐름으로 모아 보는 로컬 웹 앱입니다. 옆 모니터나 폰에 띄워 두고 구경하다가, 필요할 때만 끼어들면 됩니다.

## 왜 만들었나

UX 엔지니어로 클라이언트를 개발하다 보면 스크린샷이나 시안을 보면서 결정하거나 피드백해야 할 때가 많습니다. 동시에 클라이언트 개발 세션을 돌리면서 그 흐름을 지켜보다가 개입해야 할 때도 있습니다. 이 일을 Open Design, Claude Code, Codex, Claude Design을 오가며 합니다. 필요한 것은 모든 세션을 통째로 한곳에 모으는 대시보드가 아니었습니다. **산출물을 중심으로 흐름을 관찰하는 화면**이었습니다.

## 디자인 철학

### 세션이 아니라 산출물을 본다

관찰 대상을 세션에서 산출물로 줄입니다. 대화 전체를 미러링하지 않고, 세션별 탭이나 분할 화면도 두지 않습니다. 모든 도구의 산출물이 시간순으로 하나의 흐름에 섞여 흐르고, 세션은 발신자 이름으로만 구분됩니다.

### 관찰자이지 중재자가 아니다

gollabara는 세션에게 승인을 요구하지 않고, 질문을 새로 만들지 않습니다. 세션의 워크플로가 원래 사용자에게 묻게 되어 있을 때만 그 질문을 비춥니다. 원하면 그 질문에 잠깐 동안 앱에서 답할 수 있고, 답은 직접 입력한 것처럼 세션에 닿습니다. 그러지 않으면 질문은 평소처럼 세션에서 기다립니다. gollabara가 대신 답하는 일은 없습니다. 결정을 재촉하는 경고색이나 큰 버튼도 없습니다.

### 세션은 구경꾼을 의식하지 않는다

세션의 프롬프트나 워크플로를 이 앱을 위해 바꾸지 않습니다. 세션은 평소처럼 일하고, hook이 그 과정에서 나온 산출물을 집어 옵니다. 포착은 세션을 멈추거나 늦추지 않습니다. 서버가 꺼져 있으면 아무 일도 일어나지 않습니다.

### 판단은 사람의 눈으로

화면이 맞는지는 모델이 아니라 사람이 봅니다. 그래서 gollabara는 산출물을 판정하지 않고, 세션이 찍은 스크린샷과 시안을 받은 그대로 보여 줍니다. 이미지가 주인공이므로 각 칸의 너비는 이미지의 원래 비율을 따르고, 잘라내지 않습니다.

### 조용한 표면, 한 점의 신호

하루 종일 옆에 켜 두는 화면이라 표면은 거의 흑백인 개발 도구처럼 조용합니다. 노랑은 로고, 내가 고른 것, 주요 행동, 이렇게 세 곳에만 찍힙니다. 심볼인 열린 뷰파인더는 관찰을, 그 안의 한 점은 고르는 순간을 뜻합니다. 자세한 규칙은 [DESIGN.md](DESIGN.md)에 있습니다.

### 두 방향의 흐름

데스크톱에서 이미지는 가로로, 리캡과 질문은 세로로 흐릅니다. 하나를 고르면 다른 쪽의 짝이 함께 밝아집니다. 폰에서는 채팅만 남기고, 이미지는 탭해서 크게 봅니다.

### 보관함이 아니라 흐름

gollabara는 세션이 일하는 동안 지켜보려고 만든 앱입니다. 세션의 데이터는 그 세션이 살아 있는 동안, 그리고 끝난 뒤 한 시간까지만 남겨 두고, 그 뒤에는 메시지, 이미지, 피드백을 지웁니다. 지난 기록을 뒤져 보는 화면도, 보관 기간을 정하는 설정도 없습니다.

### 내 기기에만

산출물은 내 기기에만 저장되고, 서드파티 스토리지로 나가지 않습니다. 밖에서 볼 때도 Tailscale tailnet 안에서만 열도록 설계합니다. 공개 인터넷에는 노출하지 않습니다. 밖으로 나갈 수 있는 것은 기기마다 직접 켜는 알림 하나뿐입니다. 세션이 나를 기다린다는 신호로, 끝에서 끝까지 암호화되고 세션의 글, 이름, 이미지는 담지 않습니다. 브라우저 회사의 푸시 서버를 거치는데, 그 서버는 언제 내 기기로 알림이 가는지는 보지만 무슨 내용인지는 보지 못합니다.

서버는 이 기기와, Tailscale이 켜져 있으면 그 tailnet 주소에서만 열리므로 같은 Wi-Fi의 다른 기기는 접속할 수 없습니다. 폰에서 보려면 폰을 같은 tailnet에 연결하고 `http://<이 기기의 tailnet 이름 또는 100.x 주소>:4747`을 여세요. Tailscale을 서버보다 먼저 켜 두세요. 나중에 생긴 주소는 서버를 다시 시작해야 반영됩니다. `GOLLABARA_HOST`로 listen 주소를 바꿀 수 있습니다(쉼표로 구분, 예: `0.0.0.0`). 이때 노출 범위는 직접 책임집니다. 서버는 자기 주소와 이름으로 온 요청에만 답하므로, 브라우저의 다른 페이지가 다른 이름으로 접근할 수 없습니다. 그 밖의 이름(예: 리버스 프록시)으로 열려면 `GOLLABARA_ALLOWED_HOSTS`에 추가하세요.

## 이름

gollabara는 「골라 봐라」를 소리 나는 대로 적은 이름이고, 두 가지로 읽힙니다. 한 덩어리로 읽으면 「한번 골라 봐」이고, 끊어 읽으면 「골라라, 그리고 봐라」입니다. 두 뜻 모두 이 앱이 하라는 일입니다. 세션을 흘려보내면서 그 산출물과 결정을 지켜보고, 확인하고, 필요할 때 피드백하세요.

## 지금 상태

초기 단계입니다. 지금 되는 것은 다음과 같습니다.

- **Claude Code**: 그 안에서 실행한 Open Design 작업까지, 이미지 · 리캡 · 질문이 흐름으로 들어옵니다.
- **Codex CLI**: 리캡, 세션이 본 이미지, Plan 모드에서 묻는 질문도 들어옵니다. 피드백은 Codex 세션의 다음 단계나 턴이 끝날 때 닿고, 쉬고 있는 세션을 깨우지는 아직 못합니다.
- **개입**: 세션에 답장할 수 있고, 이미지 하나를 짚어 보낼 수도 있습니다. 피드백은 세션의 다음 단계에 닿고, 쉬고 있는 세션은 깨워서 전달합니다. 세션을 음소거하거나 한 세션만 골라 볼 수도 있습니다.
- **찾아보기**: 살아 있는 세션이 보낸 것을 위로 거슬러 올라가 보고, 세션을 이름으로 찾을 수 있습니다.
- **tailnet으로 폰에서**: Tailscale tailnet 안의 기기라면 어디서든 흐름을 열 수 있습니다.
- **알림**: 기기마다 켜 두면 세션이 질문하거나 내 피드백에 답할 때 알려 줍니다. 알림에는 세션이 한 말이 나오지 않습니다.

다음에 무엇을 어떤 순서로 하는지는 [docs/ROADMAP.md](docs/ROADMAP.md)에 있습니다. Tailscale Serve를 통한 원격 접속과 홈 화면 앱, 세션이 질문할 때 오는 알림입니다. Antigravity와 다른 도구는 MVP 이후에 이어집니다.

## 써 보기

[bun](https://bun.sh) 1.3 이상이 필요합니다.

```bash
bunx gollabara setup     # npm에 올라간 뒤
bunx gollabara doctor    # 무엇이 되고 무엇이 안 되는지
```

`setup`은 gollabara를 `~/.gollabara`에 설치하고, macOS에서는 서버를 로그인 서비스로 띄우며(http://localhost:4747), `claude`나 `codex`가 PATH에 있으면 Claude Code와 Codex CLI에 플러그인을 설치합니다. Codex는 플러그인의 hook을 한 번 검토하라고 하니, `codex`를 열어 승인하세요. 몇 번을 다시 실행해도 괜찮습니다. `bunx gollabara update`로 모두 새로 고치고, `bunx gollabara uninstall`로 지웁니다(`--keep-data`를 주면 메시지와 이미지는 남깁니다).

npm 패키지가 나오기 전에는 저장소에서 실행합니다.

```bash
bun install && bun run build
bun src/cli.ts setup     # 로그인 서비스 없이 띄우려면 bun src/cli.ts serve
```

Claude Code 세션에는 피드백이 쉬고 있을 때도 바로 닿습니다. 플러그인이 세션을 깨우므로 실행 플래그가 필요 없습니다.

개발과 설정은 [AGENTS.md](AGENTS.md)를 참고하세요.
